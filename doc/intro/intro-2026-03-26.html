Dag

Directed Acyclic Graph. Your entire pipeline.

Task

A single unit of work inside a Dag.

Operators & Decorators

Building blocks that define what a task does.

Dependencies

Implicit via TaskFlow return values, or explicit with chain(), >>, <<, [a, b] >> c for parallel.
